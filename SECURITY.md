# Security

The initial release contains specifications and documentation only; it does not
ship a YAML parser, CLI or native binding. Runtime security-support claims will
be stated alongside the first implemented release.

Report potentially sensitive security issues privately to
[security@3leaps.net](mailto:security@3leaps.net). Include the affected version or
specification section and a minimal synthetic reproduction when available.
Do not post credentials or private configuration in public issues.

General contract ambiguities can be discussed publicly using synthetic examples.
See [the resource and native-boundary decision](docs/decisions/SecDR-0001-resource-and-native-boundaries.md).

## yamlprims v0.1.0 (unreleased draft)

Initial M1 Rust core crate (`yamlprims`) and CLI (`yamlprims-cli`) release line implementing the `spec-v1.4` YAML 1.2 data layer contract.

### Highlights

- Owned `Value`, `Node`, `Integer`, `Mapping`, `Options`, and `Error` surfaces over YAML 1.2 Core scalar resolution, strict indentation, duplicate-key rejection, explicit merge policy (`Reject`, `Apply`, `AsKey`), and finite resource budgets.
- Bounded wire v1 and error envelopes with plain JSON projection and the `yamlprims` CLI (`check`, `dump`, `dump --plain`).
- Conformance qualification against pinned `structcorpus` profiles across specification revisions `spec-v1.0` through `spec-v1.4`.
- Gold-standard release provenance: signed `spec-v*` and `v*` tags, `SHA256SUMS` and `SHA512SUMS` manifests dual-signed with Minisign and OpenPGP subkey signatures, CycloneDX SBOM, and packaged source and multi-platform CLI archives.

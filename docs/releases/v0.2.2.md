## yamlprims v0.2.2

Patch release of `yamlprims` that hardens the release procedure. The library, CLI behaviour and the `spec-v1.5` contract are unchanged.

### What it ships

- **Explicit release commit:** `make release-tag` refuses unless `HEAD`, fetched `origin/main` and `YAMLPRIMS_RELEASE_COMMIT` are the same commit, and the tag is signed on that commit rather than `HEAD`. `make release-push-tag` captures each verified annotated tag object, refuses one that names another commit or moved during verification, pushes that object by id, and requires the remote to hold exactly it. `YAMLPRIMS_RELEASE_COMMIT` was documented before but was not checked.
- **Per-release environment checks:** `make release-env-check` names every per-release value (`YAMLPRIMS_RELEASE_COMMIT`, `YAMLPRIMS_EXPECTED_*`, `YAMLPRIMS_RELEASE_ANCHOR_FILE`, `YAMLPRIMS_RELEASE_RUN_ID`/`_ATTEMPT`, `YAMLPRIMS_CRATE_RUN_ID`) that belongs to another release. `eval "$(make -s release-env-reset)"` clears them. The release checklist starts with both.
- **Anchor-file binding after tagging:** once `YAMLPRIMS_RELEASE_ANCHOR_FILE` names this tag's recorded anchor, `release-verify-published-tag.sh` binds to it (including when it writes an anchor), refuses an exported `YAMLPRIMS_EXPECTED_*` that disagrees, an anchor for another tag, and a configured anchor that is not a regular file. Recorded anchors for `spec-vX.Y` tags are accepted.
- **Clearer guard errors:** the anchor, run-selection and crate-records guards print the values they compared and the likely cause.
- **npm validation lag:** the OIDC publish step verifies npm with a 120 x 15 s poll budget by default, and the `publish-npm` job timeout is 45 minutes, so a successful publish no longer fails the job while npm validates the upload.
- **Prepush preflight:** `check-tooling.py --prepush` fails at once, naming the `python3-venv` package, when the interpreter cannot create a venv. The `make doctor` yamllint floor is now 1.29.0, the Debian bookworm yamllint that the digest-pinned CI toolbox image installs (without a version pin).
- **Release checklist:** adds `make release-create-draft` before signing, removes the section 4 crate dry run that ran before `release-crates-fetch`, lists the crate publish inputs, documents npm's validation delay, adds the post-publish Homebrew tap and Scoop bucket step, and lists `YAMLPRIMS_YAML_BIN`, `YAMLPRIMS_DECERNOR_BIN` and `YAMLPRIMS_CARGO_TOKEN_FILE` in the release environment.

### Verification

The `yamlprims` CLI parses, emits, and projects YAML; it verifies no cryptographic signatures and embeds no keys. To verify this release, verify the annotated OpenPGP-signed `v0.2.2` tag and the dual-signed checksum manifests (`SHA256SUMS` and `SHA512SUMS`, signed with both Minisign and the OpenPGP release signing subkey) against the public pins committed in the tagged tree (`docs/security/` and `keys/expected-fingerprints.txt`); see [docs/security/README.md](../security/README.md) and [RELEASE_CHECKLIST.md](../../RELEASE_CHECKLIST.md).
